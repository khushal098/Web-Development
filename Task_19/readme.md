
## Laundry Service Booking Page

A web application built with HTML, CSS and JavaScript where users can browse laundry services, add them to a cart, and book them.

## Features
Navigation bar with a logo, links (Home, Services, Contact Us, About Us), the username, and a red logout button.
Added Items section that starts with "No Items Added" and updates as services are added.
Total Amount that starts at ₹ 0 and updates dynamically.
Browse Our Services section that shows one service at a time with its image, name and price.
Skip Item / Add Item buttons to move through the services or add them to the cart.
Booking form with full name, email and phone number, plus validation.
Book now button that stays disabled until at least one item is in the cart.
Confirmation message after a successful booking.
Responsive layout that stacks into one column on small screens.
