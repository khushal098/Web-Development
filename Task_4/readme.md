## How to Run

Follow these steps to view and run the project locally on your machine:

### Option 1: Direct Browser Access
1. Download or clone this repository to your computer.
2. Navigate to the project folder.
3. Double-click the `index.html` file to open it in your default web browser (Chrome, Edge, Firefox, etc.).

### Option 2: Live Server (VS Code)
1. Open the project folder in **Visual Studio Code**.
2. Install the **Live Server** extension from the VS Code Extensions tab (`Ctrl + Shift + X`).
3. Open `index.html`.
4. Right-click anywhere in the file editor and select **Open with Live Server**.
