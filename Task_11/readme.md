# Thala 7 - Sneaker Store UI
Here's a quick frontend project I put together for a sneaker store concept. I built this entirely with vanilla HTML and CSS—no React, no Bootstrap—just to practice my layout skills from scratch.

It's a single-page UI that flows through four main sections: a hero landing page, a product details view, a shopping cart, and a checkout form. I relied heavily on CSS Grid and Flexbox to get the spacing exactly right.
