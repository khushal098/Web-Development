## Student Records Web Page

A simple web page that shows student details in cards. You can search students by name, and the cards update while you type.

## What it does
Shows student records as cards (name, marks, class, address)
has a search box to find students by name
Saarch works in real time, no need to press Enter
Header and search bar stay fixed at the top
Shows No students found if nothing matches



## Built With

JavaScript
