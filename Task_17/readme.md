


## Division Using Promises

A simple web page that divides two numbers using a JavaScript Promise. It shows the result, or an error message if the division is not possible (like dividing by zero).

## What it does
Divides the first number by the second number
Uses a Promise to give the result or the error
Shows an error message when the second number is 0
Runs 7 dummy test cases automatically
Has input boxes where you can try your own numbers## Built With
