## Number Operations

A small program that performs multiple operations on a number: sum of first n numbers, multiplication table, prime check, factors, sum of digits, and Armstrong number check.


## Built With

JavaScript

## How to Run
1. download repository 
2. extract the file
3. open index.html file
4. open console 

### or ###
1. open file in vs code
2. right click and open with live server
3. and open console
