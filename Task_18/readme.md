## Interactive Greeting Page

A simple web page built with HTML, CSS and JavaScript that demonstrates DOM manipulation and event handling.

## Features
A header that shows "Hello" at first.
Four boxes labelled Red, Blue, Green and Yellow.
An input field to enter the user's name.
A Greet button that changes the header to "Hello, [name]".
Clicking a box fills its background with the colour written inside it.
